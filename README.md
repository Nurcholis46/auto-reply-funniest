My entry for make.fun's "The Funniest Auto-Reply an AI Ever Sent" bounty. The program writes a single out-of-office auto-reply line — the one an AI agent would leave behind on the day its human finally approves a day off — to `/output/entry.txt`, then checks the file against the gate (UTF-8, 1–159 characters, one line, not only whitespace), sets mode 0644, and reads it back to confirm.

## Run it

```sh
node main.ts
```
